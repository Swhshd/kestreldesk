# Changelog

## KestrelDesk 0.1

Initial KestrelDesk distribution.

- Added KestrelDesk presentation and bilingual product documentation.
- Includes customer identity isolation, employee realtime authorization/session revocation, WebSocket lifecycle hardening, provider-safe Agent Tool Aliases, and Guest Recovery A2.
- Added safer Docker operator configuration with required database/customer-session inputs and no reusable default database credential.
- Documented self-hosting, local administrator recovery, SMTP setup, AI/RAG setup, and current platform limitations.
- Included the Apache-2.0 license text.

Known limitations are listed in [README.md](README.md) and [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
